# 마크다운(Markdown) 문법 총정리

마크다운은 간단한 기호를 사용해 텍스트 서식을 지정할 수 있는 가벼운 마크업 언어입니다.

---

## 1. 제목 (Headers)
텍스트 앞에 `#` 기호를 붙여 제목을 만듭니다. `#` 개수가 많아질수록 글씨 크기가 작아집니다. (1단계부터 6단계까지 지원)

# 1단계 제목 (가장 큼)
## 2단계 제목
### 3단계 제목
#### 4단계 제목
##### 5단계 제목
###### 6단계 제목 (가장 작음)

---

## 2. 텍스트 스타일 (Text Styles)
글자를 굵게, 기울임, 혹은 취소선으로 강조할 수 있습니다.

*기울임꼴(이탤릭)* 또는 _기울임꼴_
**굵은 글씨(볼드)** 또는 __굵은 글씨__
***굵은 기울임꼴***
~~취소선~~

---

## 3. 리스트 (Lists)
순서가 없는 목록과 순서가 있는 목록을 작성할 수 있습니다.

### 순서 없는 목록
* 항목 1
  * 하위 항목 1-1 (스페이스바 2번 또는 Tab으로 들여쓰기)
* 항목 2

### 순서 있는 목록
1. 첫 번째 항목
2. 두 번째 항목
3. 세 번째 항목

---

## 4. 링크 및 이미지 (Links and Images)
웹 주소를 연결하거나 이미지를 본문에 삽입합니다.

[구글 홈페이지 바로가기](https://www.google.com)

![이미지 대체 텍스트](https://via.placeholder.com/150)

---

## 5. 인용구 (Blockquotes)
문장이나 중요한 메모를 강조할 때 텍스트 앞에 `>` 기호를 붙입니다.

> 이것은 인용구입니다.
> 여러 줄을 연속으로 작성할 때는 줄마다 기호를 붙여줍니다.

---

## 6. 코드 블록 (Code Blocks)
소스 코드나 명령어를 별도의 서식으로 표시할 때 사용합니다.

### 인라인 코드
문장 중간에 `int a = 10;`과 같이 짧은 코드를 넣을 때는 백틱(`) 1개로 감쌉니다.

### 블록 코드
여러 줄의 코드를 작성할 때는 위아래를 백틱 3개(```)로 감싸고, 첫 백틱 뒤에 해당 언어 이름을 적어주면 구문 강조(Highlighting)가 적용됩니다.

```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
